# DCA Bot — Binance

Hey! I'm Enzo, a complete beginner in Python programming.

As a first real project, I decided to build a DCA (Dollar Cost Averaging) bot that automatically buys BTC every day on Binance. I figured it was a good way to learn by doing something I actually care about — crypto.

The bot is simple: it connects to Binance via API, checks the USDT balance, places a market buy order, and waits 24 hours before doing it again.

## Tech used
- Python
- Binance API
- python-binance
